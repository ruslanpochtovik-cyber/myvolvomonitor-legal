# MyVolvoMonitor

## Terms of Use and Privacy Policy

Effective date: November 26, 2026

### 1. Application purpose

MyVolvoMonitor is an independent, private, non-commercial, self-hosted application intended exclusively for personal monitoring of Volvo vehicles owned by its operator.

### 2. Vehicle data

The application uses official Volvo Cars APIs to retrieve authorized read-only vehicle data, including vehicle status, diagnostics, energy consumption, charging information, mileage, fuel levels, location and historical statistics.

### 3. Read-only operation

The application does not provide remote vehicle control, vehicle unlocking, engine activation, climate control or modification of vehicle settings.

### 4. Data storage and privacy

Vehicle telemetry is intended to be stored locally on the operator's private server. Access is restricted to authorized users. Vehicle data is not sold, publicly disclosed or used for advertising.

Data retention is subject to applicable laws and Volvo Cars API terms and conditions.

### 5. Security

The application is designed to use encrypted communications, restricted OAuth permissions, protected credential storage and private network access.

### 6. Authorization and data deletion

The vehicle owner may withdraw authorization, discontinue monitoring and delete locally stored vehicle data at any time.

### 7. Third-party services

The application depends on official Volvo Cars APIs and their availability. Volvo Cars may change, restrict or discontinue access to these services.

### 8. Disclaimer

MyVolvoMonitor is an independent personal project and is not an official Volvo Cars product. It is not affiliated with, endorsed by or sponsored by Volvo Car Corporation.

The application is intended for informational purposes only and must not be relied upon for safety-critical decisions.

### 9. Changes

These terms may be updated to reflect changes in functionality, security requirements or applicable Volvo Cars API terms.
